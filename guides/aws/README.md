# AWS guides

Each guide builds one network path by hand in the AWS Management Console and
the Databricks account console.

- [Connectivity choices](connectivity.md): how classic and serverless compute
  differ, and which path to choose.
- [Classic compute guides](classic/README.md): VPC peering, PrivateLink,
  Transit Gateway, and workspace back-end PrivateLink.
- [Serverless compute guides](serverless/README.md): NCC and PrivateLink.
- [Kafka](kafka/overview.md): listener design and paths for both compute
  types.

To deploy the same scenarios as labs, see
[Lab scenarios](../operations/lab-scenarios.md#aws).
